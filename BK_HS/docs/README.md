# Documentación — Hidro Smart Backend

- `architecture/`: arquitectura y diagramas.
- `database/`: PostgreSQL, tablas, relaciones y decisiones.
- `api/`: endpoints REST, DTOs y respuestas.
- `mqtt/`: tópicos y payloads MQTT.
- `iot/`: ESP32, YF-S201, electroválvula e hidrobomba.
- `security/`: JWT, roles, permisos y seguridad.
- `deployment/`: Docker y despliegue.
- `testing/`: estrategia y evidencias de pruebas.
- `requirements/`: requisitos relacionados con backend.
- `decisions/`: decisiones técnicas (ADR).

La documentación debe mantenerse alineada con el código y la BD real.
